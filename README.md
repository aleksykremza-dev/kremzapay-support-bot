# kremzaPay Support Bot

RAG support bot for kremzaPay — a fictional payment provider created for this
portfolio project. Answers merchant and buyer questions in English and Polish
strictly from the included knowledge base (242 articles, 10 categories), and
escalates to a human when the documentation has no answer.

Stack: Python 3.12 + uv, Qdrant (Docker), Ollama (local LLM), fastembed.
Runs fully local, no paid APIs.

**Disclaimer:** kremzaPay is not a real company. All documentation in `kb/`
is demo content created for this project and has no legal or informational value.
