# Two-factor authentication for the Panel

Two-factor authentication (2FA) adds a second step to Panel sign-in. Alongside your password, you enter a temporary code from an authenticator app, so a stolen password alone is not enough to access your account.

kremzaPay uses TOTP codes generated by a standard authenticator app on your phone. 2FA is required for anyone with the Admin role and recommended for all team members, whatever their role.

To enable it:

1. Open Settings → Security in the Panel.
2. Choose to set up two-factor authentication.
3. Scan the shown QR code with your authenticator app.
4. Enter the current code from the app to confirm.

Once enabled, you will be asked for a code from the app each time you sign in.

When you set up 2FA, the Panel shows a set of backup codes once. These let you sign in if your phone is unavailable. Save them offline — for example printed or in a password manager — because they are shown only that one time and cannot be displayed again. Each backup code works once.

If you lose your device and your backup codes, you can still recover access. Contact support to start account recovery; you will need to verify your identity before 2FA is reset. Open a ticket in the Panel from another signed-in team member, or write to pomoc@kremzapay.demo (Mon–Fri 8:00–18:00 CET). There is no phone support, so keep your backup codes safe to avoid delays.

For team access, manage roles under Settings → Team, and make sure every Admin has 2FA switched on.
