# Multiple partial refunds

You do not have to return a payment all at once. kremzaPay lets you issue partial refunds repeatedly against the same payment until the returned total reaches the original amount. This is useful when you refund an order item by item, or agree to return an amount in stages.

## How it works

1. Open the **Refunds** section.
2. Create a partial refund for the amount you want to return now.
3. Repeat as needed, creating a new partial refund each time.

You can keep issuing partial refunds until the sum of all refunds equals the original payment amount. Once the full amount has been returned, the payment is fully refunded and no further refunds can be created for it.

## What you will see

Each partial refund appears **separately** in the **Refunds** section, with its own status and amount. The same refunds also appear individually in the settlement report in the **Reports** section, so the running total is always traceable line by line.

## You cannot exceed the original amount

The system will not let the combined refunds go beyond the original payment amount. If you try to refund more than remains, the refund cannot be created. Check the amount already returned in the **Refunds** section before issuing the next partial refund.

Each partial refund follows the normal statuses and returns to the buyer within 1–5 business days. Partial refunds are available within the 180-day window from the original payment. If a partial refund is rejected, contact support through the Panel ticket system or pomoc@kremzapay.demo.
